## 이번 세션에서 해결한 문제들

### 1. Goal Pose 설정해도 로봇이 안 움직이는 문제 (BT is_recovery 오류)

**증상:**
```
[ERROR] [bt_navigator]: Exception when loading BT: a port with name [is_recovery]
is found in the XML (<Wait>, line 30) but not in the providedPorts()
[ERROR] [bt_navigator]: Error loading XML file: nav2_bt_obstacle_wait.xml
[ERROR] [lifecycle_manager_navigation]: Failed to bring up all requested nodes.
[INFO] [bt_navigator]: Action server is inactive. Rejecting the goal.
```

**원인:**  
Nav2 Jazzy에서 `Wait`, `BackUp`, `Spin` BT 노드는 `is_recovery` 속성을 지원하지 않음.  
커스텀 BT XML에 `is_recovery="true"` 를 붙였더니 BT 로드 실패 → bt_navigator 비활성화 → 모든 Goal 거부.

**수정 파일:** `nav2_bt_obstacle_wait.xml`
```xml
<!-- 수정 전 -->
<Wait wait_duration="10" is_recovery="true"/>
<BackUp backup_dist="0.30" backup_speed="0.15" time_allowance="10"
  error_code_id="{backup_error_code}" is_recovery="true"/>
<Spin spin_dist="1.57" time_allowance="10"
  error_code_id="{spin_error_code}" is_recovery="true"/>

<!-- 수정 후 -->
<Wait wait_duration="10"/>
<BackUp backup_dist="0.30" backup_speed="0.15" time_allowance="10"
  error_code_id="{backup_error_code}"/>
<Spin spin_dist="1.57" time_allowance="10"
  error_code_id="{spin_error_code}"/>
```

### 2. 경로가 벽을 뚫고 지나가는 문제 (allow_unknown)

**증상:** 웨이포인트 5개 찍고 실행하면 경로가 벽/미탐색 구간을 직선으로 뚫고 지나감

**원인:**
```yaml
global_costmap:
  track_unknown_space: true   # 미탐색 영역을 "미지" 상태로 추적
planner_server:
  allow_unknown: true          # 미지 영역을 통과 가능으로 취급 ← 문제
```
SLAM 맵에서 탐색 안 된 회색 영역을 NavfnPlanner가 통과 가능으로 보고 최단 경로를 뚫음

**수정 파일:** `nav2_params.yaml`
```yaml
# 수정 전
allow_unknown: true
# 수정 후
allow_unknown: false
```

### 3. 동적 장애물 회피 기능 추가 (RPP → DWB)

**목적:** 사람/물체가 경로에 있을 때 공간이 있으면 자동 우회, 없으면 기다림

**변경 내용:**

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 컨트롤러 | RegulatedPurePursuitController | **DWBLocalPlanner** |
| 장애물 대응 | 멈춤 후 리커버리 | 옆으로 우회 (공간 있을 때) |
| 대기 시간 | 10초 | **30초** (사람이 비켜줄 때까지) |
| BT 리커버리 순서 | ClearCostmap→Spin→Wait→BackUp | **Wait(10s)→ClearCostmap→Wait(10s)→BackUp→Spin** |
| BT 재시도 횟수 | 6회 | **8회** |

**신규 파일:** `nav2_bt_obstacle_wait.xml`  
**수정 파일:** `nav2_params.yaml`

## DWB 동작 원리 (참고)

```
Goal Pose 설정
    ↓
NavfnPlanner — 전역 경로 계산 (1Hz 리플래닝)
    ↓
DWBLocalPlanner — 매 주기(20Hz)마다 수십 가지 (속도, 각속도) 조합 시뮬레이션
    ├─ 장애물 없는 궤적 존재 → 가장 점수 높은 궤적으로 이동 (자동 우회)
    └─ 모든 궤적 막힘 → FAILURE
          ↓
    Recovery (최대 8회)
    1. Wait(10s) — 사람이 비켜주길 기다림
    2. ClearCostmap — 유령 장애물 제거
    3. Wait(10s) — 한 번 더 대기
    4. BackUp(0.30m) — 살짝 후진
    5. Spin(1.57rad) — 최후 수단
          ↓ 8회 실패 시
    Navigation FAILED
```

## 주의사항

- `allow_unknown: false` 설정 시 SLAM 맵에서 탐색 안 된 회색 영역으로는 경로 생성 불가
  → 맵을 꼼꼼히 탐색할수록 경로 옵션 증가
- nav2.sh 재시작 없이 파라미터 수정해도 반영 안 됨 (항상 재시작 필요)
- `./nav2.sh` 뒤에 yaml 경로 생략 가능 (기본값: `~/my_map.yaml`)
